## English

**Name:** Mount HUD: Hunger, XP & Horse Stats

No loader, Minecraft version or other mods' names in the name: CurseForge shows those as tags, and the name stays right as versions are added.

**Summary:** Keep your hunger bar and experience bar visible while riding a horse, camel, pig or strider: the mount's hearts sit above hunger or on the left, the jump bar shows only while charging a jump, and the horse inventory shows speed and jump height.

246 characters (CurseForge allows up to 250).

**Categories:** Utility, Game Mechanics

**Environment:** Client only

**Dependencies:** Mod Menu (optional on Fabric / Quilt). Fabric API is not required.

**License:** MIT.

**Links:** source `https://github.com/Shamanalle/mount-hud`, issues `https://github.com/Shamanalle/mount-hud/issues`.

**Icon:** `icon.png` (512x512).

### CurseForge setup checklist

1. Create/update the project on CurseForge (*Minecraft → Mods*, Project ID `1794326`) with the name, summary, categories, icon, license and links above.
2. Paste the English section of `docs/project-page.md` into the CurseForge description, and upload the pictures from `docs/gallery.json` under *Images* with the titles and descriptions listed there; mark the first one as the featured image.
3. Keep `"curseforge": "1794326"` in `.github/publish.json` and set the `CURSEFORGE_TOKEN` repository secret (`CONTRIBUTING.md`).
4. Publish the release via *Actions → Publish Release*.
